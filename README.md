# Silent Frame Logistics

A logistics marketplace in preparation for Krugersdorp and the West Rand, Gauteng.

The GitHub Pages site is currently a public-facing pilot preview. The refreshed pages explain transport requests, vehicle fit, provider checks, pricing inputs, and the proposed 15% / 85% commission. Live bookings, transport verification, price recommendations, card checkout, payment splitting, and payouts still require backend work and business/provider decisions.
